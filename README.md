# e-plantShopping

**e-plantShopping** es una aplicación web interactiva desarrollada en React diseñada para la compra de plantas de interior y accesorios de jardinería. El objetivo principal es ofrecer a los usuarios una experiencia de compra intuitiva, fluida y moderna.

## 🌿 Características principales

- **Catálogo de productos:** Exploración de una variedad de plantas organizadas por categorías con detalles de cuidado y precios.
- **Carrito de compras:** Funcionalidad para agregar, eliminar y modificar la cantidad de artículos en tiempo real.
- **Cálculo automático:** Actualización automática del subtotal y del costo total de la compra.
- **Navegación fluida:** Interfaz responsiva e interactiva construida con componentes reutilizables de React.

## 🛠️ Tecnologías utilizadas

- **React.js**
- **JavaScript (ES6+)**
- **HTML5 & CSS3**
- **Vite** (o Create React App)
